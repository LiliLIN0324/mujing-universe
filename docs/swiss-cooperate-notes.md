## 原则

1. 网格管关系。标签、事实、线在同一套栏里，不靠白卡片把内容围起来。
2. 层级靠字号和字重。大的是页名和可执行的事实，小的是栏目名。
3. 少字。每一行只留一件事。说明、步骤、免责长段都不进这一页。
4. 留白跟着格子走。行与行之间留一条缝，不把整屏空掉。
5. 对比要硬。墨色 `#1A1A1C` 落在纸色 `#F6F5F3` 上，分隔用细线。直角，不用胶囊。
6. 只留一个动作语气。这一页的动作是联系：飞书、微信、邮件。Mimi 是旁边一句，不是主角。
7. 手机上栏可以收成一行，顺序不变：范围、飞书、微信、邮件、Mimi。

## 三处对照里用得上的

- **Swiss Style**：格子是结构，不是装饰。合作页用左栏标签、右栏事实。
- **Swiss Brut**：「Let's talk」是联系本身，旁边直接给邮件和电话。我们对应成飞书、微信、邮件三行，不写流程。
- **FF Minimal**：联系收成一句加地址。邮件行只留地址。
- **GitHub Universe**：栏目名像 `in-person/`、`virtual/`，下面是事实和价格，边角是直角。我们用短栏目名，不用圆角按钮。
- **Firm Studio 作品页**：一件作品是标题加一行。合作页借这个层级；作品库的网格以后再对，这次不改。
