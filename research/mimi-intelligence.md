# Mimi 智能体「不智能」诊断与优化方案

> 2026-11-14 · 基于线上实测（`https://mujing-universe.pages.dev/api/chat`）与本地代码走查
> 诊断人：Mavis　状态：第一档已落地（见「已修」），第二档待终树拍板

## 一句话结论

「Mimi 不智能」不是一个问题，是**四个叠在一起的问题**。真正让访客「觉得它笨」的排第一的不是模型笨，是**它经常直接罢工**：

| # | 问题 | 访客的实际感受 | 严重度 |
|---|---|---|---|
| 1 | 上游免费模型被限流，智能体频繁返回失败 | 「抱歉，这次没能生成回答，请稍后再试。」 | 致命 |
| 2 | 模型只有 8B，会编作品名、编假链接 | 答案里出现从没听过的作品，链接点进去是空页 | 高 |
| 3 | 作品事实手写进提示词，一长就飘 | 同一个问题两次答案不一样 | 中 |
| 4 | 保密口径与首页自相矛盾 | 首页写着「当代西湖繁胜全景图」，问智能体却说「还在保密期」 | 中 |

## 实测证据

### 1. 上游限流：11 次请求，9 次直接失败

线上连续打 `/api/chat`（同一问题，间隔 6s / 15s）：

```
try 1 -> HTTP 200
try 2 -> HTTP 502 {"error":"upstream"}
try 3 -> HTTP 502 {"error":"upstream"}
try 4 -> HTTP 502 {"error":"upstream"}
…等 65 秒…
retry 1 -> HTTP 200
retry 2 -> HTTP 502
retry 3 -> HTTP 502
```

规律很清楚：**主模型（`Qwen/Qwen3-8B`，SiliconFlow 免费档）大约每分钟才放行 1 个请求**，其余全部 502。而 `functions/api/chat.ts` 收到非 2xx 直接 `return json({error:'upstream'}, 502)`，**零重试、零备用模型、零降级**；前端 `src/scripts/mimi-core.js` 看到 502 就 `failed = true`，给访客一句道歉。

**换算下来：真实访客问一句，命中失败的概率约 80%。** 这是「不智能」的第一来源，跟模型聪明不聪明无关。

（旁证：SiliconFlow 的限流**按模型分别计算**，一个模型超限不影响另一个 —— 这正是下面「换模型」这条解法成立的依据。）

### 2. 8B 模型会编

同一句「你们有哪些作品？想看代表作」，两次实测答案完全不同：

```
① 我们有数字展陈、民乐音画、古画再创作、活动布置、商品营销图与短视频这些方向的作品。
  比如 [三维活动布置工作台](/works/scendance/)、[虚拟影棚](/works/anyreal/)、
  [AI 创意画板](/works/dragon-diffussion/)、[转塘艺讯](/works/zhuantang-yixun/)。

② 我们做过不少有意思的事，比如 [数字艺术空间](/works/scendance/)、
  [水利交通调度](/works/)、[音乐创作](/works/)、[AI 创意画板](/works/dragon-diffussion/)…
```

第②次里有两个问题：

- **「水利交通调度」根本不存在** —— 提示词里没有这个主题，是模型现编的。
- **作品名被改写**：「幕景 Scendance」→「数字艺术空间」，「民乐音画」→「音乐创作」。链接还是挂的泛路径 `/works/`，点进去是个空目录。

提示词里明明写了「清单里没有的路径一律不要造」，但**8B 模型扛不住 2000 多字的提示词，光靠劝是劝不住的**。

### 3. 提示词里的占位符被模型照抄

提示词原文有一句：`格式照抄 [文字](/works/…)`。模型把它当模板学走了，真的输出 `[文字](/about/)` —— 一个指向 `/about/` 的「文字」链接。

**教训**：给模型的链接示例必须用**真实例子**，不能用占位符。

### 4. 多轮记忆其实是好的

「我叫丁小丁，记住我的名字」→ 隔两轮再问「我叫什么名字」「我刚才说我叫什么了吗」，模型三次都答对了。

**所以上下文长度不是瓶颈**（虽然还是从 8 条放宽到 16 条，多多益善）。这一条要记下来，免得以后误判方向。

## 已修（第一档，本 PR，零风险、不花钱）

1. **换模型 + 有限重试**（`functions/api/chat.ts`）
   主模型不通就换 `Qwen/Qwen2.5-7B-Instruct` → `THUDM/GLM-4-9B-0414`。三个限流池子摊开，可用吞吐约三倍。每模型最多试 2 次（间隔 500ms），整体 22 秒预算，不让访客干等。上游状态码写进响应头 `x-mimi-upstream`，Cloudflare 日志里能直接看到。

2. **失败时这一轮退回本地答案**（`src/scripts/mimi-core.js`）
   502/503/504 → 用本地常见答案回话，并在消息下加一行「（暂时只能用常见答案回复你）」。
   **刻意不把整个会话打成模板态** —— 上游限流是分钟级的，一次限流就塌成模板问答，比失败更伤。下一轮照常再试真模型。

3. **站内链接白名单**（`functions/api/_mimi-text.js`）
   路径要在白名单里，**且链接文字要和路径对得上**，否则剥成纯文字。外链只放行 GitHub。
   顺手解决了跨分片问题：链接写到一半会先扣住，拼齐了再一起校验。

4. **提示词事实纪律**（`functions/api/chat.ts`）
   加了 5 条硬约束（只认清单、作品名照抄、不给清单外主题安名字、链接文字与路径对应、一次最多提 3 件）；把 `[文字]` 占位符换成 `[幕景 Scendance](/works/scendance/)` 真实例子；「三行」改成「三句」（信息量差别不小）。

5. **上下文 8 → 16 条消息**（前后端同步改）

6. **开场白改成直说能帮什么忙**：
   `嗨，我是 Mimi。想知道幕景在做什么、怎么合作，或者随便看看，都可以问我。`

7. **回归测试 25 组**（`scripts/test-mimi.mjs`，已接进 `prebuild`）
   覆盖：COOP/鸡场标记协议不被改坏、链接白名单各种情况、前端各状态码的降级行为、
   以及**白名单 / 提示词 / 作品目录三方的路径拼写必须一致**（这次开发中就踩到过 `scandance` 拼错的坑）。

## 待决（需要终树 / 丽丽拍板）

### ① 保密口径和首页打架 —— 建议尽快定

首页 hero 大标题就是「当代西湖繁胜全景图」，精选区还写着：

> 当代西湖繁胜全景图，是幕景宇宙正在进行的音画长卷。以宋画的观看方式重绘今日西湖，舟船、岸线与人烟由声音转译生成。这一卷仍在创作中。

但后端 `BANNED = /西湖|繁胜全景|xihu-panorama/i` 会把任何提到这三个词的模型回答整段换成「这一件还在保密期，我不方便展开」。

**访客照着首页问「你们首页那幅画是什么」，智能体却说还在保密期** —— 这大概是「不智能」最直观的一次，而且它看起来像在撒谎。

三个选项：

- **(a) 彻底保密**：连作品名都不许提。→ 首页得改（大标题、精选文案、作品页都得撤），改动面大。
- **(b) 公开到「进行中」为止（建议）**：允许提作品名和一句话介绍，不给细节、不给链接。→ 只改后端正则和提示词口径，首页不动。
- **(c) 完全公开**：跟其它作品一样对待。→ 需要丽丽确认素材和文字能不能给。

### ② 换更聪明的模型 —— 涉及花钱

免费档就是 8B–9B 级别，**不充值就换不出明显更聪明的模型**。按官网实际流量，月成本量级很小：

| 模型 | 输入 ¥/百万 token | 输出 ¥/百万 token | 备注 |
|---|---|---|---|
| `Qwen/Qwen3-8B`（现用） | 0 | 0 | 免费，但限流到「每分钟 1 个」 |
| `Qwen/Qwen3-30B-A3B` | 1.26 | 1.26 | 便宜，够用 |
| `deepseek-ai/DeepSeek-V4-Flash` | 1.00 | 2.00 | 便宜 |
| `Qwen/Qwen3-235B-A22B-Instruct` | 2.50 | 10.00 | 最强，最贵 |

**做法**：在 Cloudflare 控制台加一个环境变量 `SILICONFLOW_MODEL`（改完要重新部署），代码已经支持，不用改代码。模型名以 SiliconFlow 实时价格页为准。

### ③ 作品事实别再手写进提示词（架构级，不急）

现在作品清单是手抄在 `functions/api/chat.ts` 的提示词里的 —— 作品一多就飘，改一次要发一次版。
下一步可以做成：构建时从 `src/content/works/*.json` 自动生成一份索引，后端按问题检索最相关的 3–5 件注入提示词。好处是**作品上下线、标题改动，提示词自动跟着变**，也天然屏蔽未公开作品。
